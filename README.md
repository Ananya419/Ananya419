## Selected work

**[NeuroInsight AI](https://github.com/Ananya419/Neuroinsight_AI)** — 3D brain-tumour segmentation from MRI<br>
A 3D U-Net that segments tumour sub-regions across four MRI modalities (T1, T1ce, T2, FLAIR), served through a FastAPI backend with Grad-CAM explainability and voxel-level uncertainty maps.<br>
`PyTorch` `3D U-Net` `FastAPI` `ONNX Runtime` &nbsp;*Team project — I owned data preprocessing, model training and evaluation.*

**[N100 Financial Intelligence](https://github.com/Ananya419/summer_Internship_2026/tree/main/n100_financial_intelligence)** — analytics platform for Nifty 100 companies<br>
Built during my Bluestock Fintech internship: a validated ETL pipeline into SQLite, a financial-ratio engine, a stock screener with six preset strategies, peer comparison, k-means clustering of companies, a FastAPI service, an eight-page Streamlit dashboard and auto-generated PDF tear-sheets.<br>
`Pandas` `SQLite` `scikit-learn` `FastAPI` `Streamlit` `ReportLab` &nbsp;*Solo internship project.*

**[OptimFlow](https://github.com/Ananya419/OptimFlow)** — multi-agent operations platform for live venues<br>
Models a stadium as a live flow graph with a single crowd-flow score. An orchestrator agent built with Google ADK on Gemini coordinates specialist agents for safety triage, forecasting and routing, behind a FastAPI backend and a Next.js front end.<br>
`Google ADK` `Gemini` `FastAPI` `Next.js` `Cloud Run` &nbsp;*Built with [@shri-ram07](https://github.com/shri-ram07).*

**[SymptomIQ](https://github.com/Ananya419/SymptomIQ)** — symptom-based health prediction<br>
A Flask app that predicts likely conditions from reported symptoms with a TensorFlow model, then uses the Gemini API to generate guidance and suggest specialists near the user's location.<br>
`TensorFlow` `Flask` `Gemini API` `Pandas` &nbsp;*Team of 2 — I led data collection (15 public medical datasets), research and data analysis.*
